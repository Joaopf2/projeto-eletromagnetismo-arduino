📋 Sobre o Projeto
Projeto acadêmico desenvolvido para estudos de eletricidade e magnetismo, envolvendo cálculos de tensão, análise de circuitos e simulações práticas utilizando Arduino.

🎯 Objetivos
.Análise de circuitos elétricos

.Cálculos de tensão e corrente

.Simulação de fenômenos eletromagnéticos

.Desenvolvimento de dashboard interativo para visualização de dados

🛠️ Tecnologias Utilizadas
Microcontrolador: Arduino

.Linguagem: C++ (Arduino IDE)

.Visualização: Dashboard Interativo

.Documentação: Relatórios em PDF

.Simulação: Tinkercad


🚀 Como Usar
Pré-requisitos
Arduino IDE

.Componentes eletrônicos básicos

.Software para visualização de PDF

1. Clone este repositório:

git clone https://github.com/Joaopf2/projeto-eletromagnetismo-arduino.git

2. Abra o arquivo Código do Projeto.ino na Arduino IDE

3. Carregue o código para sua placa Arduino

4. Siga as instruções do relatório para montagem do circuito
